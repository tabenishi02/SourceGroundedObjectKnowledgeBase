## 3. Amended N-04 task definition

### N-04 [P0] — AI Knowledge Access Boundaryを受入試験する

代表3用途を使って、SGOKBが外部Consumerへ正しいKnowledgeをpublic read boundaryから提供できることを確認する。

1. Character Knowledge → Roleplay Consumer boundary
2. Similar Work retrieval → Comparison Consumer boundary
3. Concept A/B Knowledge → Creative Consumer boundary

formal evaluation:

- public MCP / Application read boundary
- correct Object / current accepted Version
- purpose-specific Context construction
- Similarity → Context integration
- traceability
- budget / omission / truncation contract
- canonical invariance
- integrity / regression

formal evaluationから除外:

- Consumer LLM output quality
- hallucination / unsupported claim generated by Consumer
- Roleplay / comparison / creative quality
- Knowledge coverage sufficiency
- Grounded Generation certification
- Atomicity / Content-Type classifier
- source-fact / interpretation verifier
- Frozen 47 confirmation
