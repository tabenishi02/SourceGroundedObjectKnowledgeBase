## 3. G-23D frozen input to G-23E

Stage 2 factual authority is Certified Content only.

Minimal model-facing projection:

```json
{
  "certified_fact_id": "CF1",
  "claim_text": "exact certified text"
}
```

Stage 2 logical response:

```json
{
  "blocks": [
    {
      "block_kind": "main",
      "certified_fact_ids": ["CF1", "CF2"]
    },
    {
      "block_kind": "interpretation",
      "candidates": [
        {
          "claim_text": "...",
          "premise_fact_ids": ["CF1", "CF2"]
        }
      ]
    },
    {
      "block_kind": "creative",
      "candidates": [
        {
          "claim_text": "..."
        }
      ]
    }
  ]
}
```

Application assigns paths from output slots:

```text
main fact ID
  -> certified_fact_materialization
  -> source_fact

interpretation candidate
  -> stage2_interpretation_candidate
  -> interpretation

creative candidate
  -> stage2_creative_candidate
  -> creative_addition
```

Important G-23D decisions:

- source fact text is not generated by Stage 2;
- model selects Certified Fact IDs; application materializes exact certified text;
- factual paraphrase does not inherit certification;
- interpretation uses `premise_fact_ids[] >= 1` and Certified Fact IDs only;
- creative is allowed only for `purpose = creative`;
- no model-authored `context_limit` path;
- no model-authored `stylistic_expression` path;
- normal output has `main`, `interpretation`, `creative` blocks only;
- each block kind cardinality is 0 or 1;
- duplicate block kind is deterministic failure;
- block order is presentation order, not semantic authority;
- `blocks: []` may mean no presentation proposal, not context-limit;
- interpretation / creative model text remains subject to V2 residual semantic validation;
- interpretation additionally requires V4I derivation validation.

## 5. Provider schema must not become semantic authority

Provider schema may enforce structural invariants such as:

```text
required fields
additionalProperties = false
array min/max items
allowed discriminator values
basic ID/string shape
block object shape
```

Provider schema must not be interpreted as proving:

```text
semantic Atomicity
Content-Type correctness
support / entailment
interpretation derivability
creative factual safety
certification
```

Application deterministic validation remains mandatory where provider schema cannot express or reliably enforce an invariant.

## 6. Retry boundary

Retry remains stage-local.

### Stage 1

Retry may address:

```text
malformed/schema output
invalid support ref
NON_ATOMIC / AMBIGUOUS
content-type mismatch
unsupported source fact
```

Retry does not change Grounded Context, context fingerprint, purpose, or factual authority.

### Stage 2

Retry may address:

```text
malformed/schema output
duplicate/invalid presentation blocks
invalid Certified Fact binding
interpretation premise failure
Atomicity / content-type failure
interpretation derivation failure
creative scope violation
```

Retry does not reopen raw Grounded Context or permit new source fact generation.

Detailed terminal policy must remain fail-closed.
