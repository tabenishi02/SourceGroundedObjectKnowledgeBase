## Candidate E contract

### Candidate acquisition unchanged

```text
object_overview ANN
Facet ANN
Statement ANN
        -> candidate Object union
```

Keep current source query and ANN bounds unchanged.

### Canonical Facet anchor retained from Candidate D

A Facet cluster is eligible only if the candidate has canonical same-Facet membership in the active generation/current accepted Version.

Facet ANN appearance is not the anchor condition.

Statement discovery may introduce a candidate even when Facet ANN misses. When canonical anchor exists, reuse stored embeddings to compute/recover direct Facet cosine as needed.

No canonical anchor => no eligible cluster.

### Statement aggregation — retain all selected-query observations

After existing per-source-query candidate-Object deduplication, retain every candidate Statement observation generated by the already-selected source Statement queries for the same Facet.

Do not apply score-based top-k inside a Facet.

Global source Statement query cap remains 12, therefore:

```text
candidate Statement observations total <= 12
candidate Statement observations in one Facet <= 12
```

For Facet `F`:

```text
statement_mean(F)
  = arithmetic mean(all retained bounded same-Facet observations)
```

### Facet-local score

If retained Statement observations exist:

```text
cluster(F)
  = (.30 * facet_similarity(F)
     + .20 * statement_mean(F)) / .50
```

If no retained Statement observation exists:

```text
cluster(F) = facet_similarity(F)
```

No statement-only branch.

### Object detail median

For all eligible canonical anchored Facet clusters:

```text
detail_median = median(cluster scores)
```

Ordinary median:

- odd count -> middle sorted score;
- even count -> arithmetic mean of two middle scores.

No max, top-k Facet selection, threshold, exponent, temperature, coverage bonus, missing prior or Class-specific rule.

Final score:

```text
object_score
  = .50 * bounded overview
  + .50 * detail_median
```

No eligible Facet cluster:

```text
detail_median = 0
```

Semantic interpretation:

> overall Object Similarity = broad Object-level similarity + typical shared canonical Facet similarity.

Missing Facets are unknown/not observed, not zero. `shared_facet_count` is support metadata, not a score multiplier.
