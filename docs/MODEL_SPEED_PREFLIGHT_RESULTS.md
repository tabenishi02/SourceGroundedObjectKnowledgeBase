## 未取得4モデルの原因

全24件がHTTP 400。モデル未取得・ロード失敗ではなく、共通の`reasoning: off`指定が拒否された。

| モデル | API応答で確認した制約 | 補足試験で必要な変更 |
|---|---|---|
| GPT-OSS 20B | low / medium / highのみ対応 | lowなどの別条件を設定 |
| Mistral Small 3.2 | reasoning設定を公開していない | reasoningパラメータを省略 |
| Ministral 3 14B Reasoning | onのみ対応 | onを使い、推論tokenを別計測 |
| Muse Glimmer | low / medium / high / xhighのみ対応 | lowなどの別条件を設定 |

これらは共通条件への不適合であり、モデルが推論不能という判定ではない。元runを`--resume`してもcompletedなので再実行されない。補足試験には別条件ID・新しい出力先が必要で、元の測定記録を上書きしない。本確認では条件変更や再推論は実施していない。
